# hotel booking page
A simple hotel booking page built with HTML and CSS.  
This project demonstrates a clean and responsive design for a hotel booking interface.

## Features
- Modern layout using HTML and CSS
- Booking form for hotel reservations
- Responsive design for different screen sizes
- Easy to customize and extend

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/hanniya5003/hotel.git
   Open the project in WebStorm (or any editor).

Open index.html in your browser to view the page.
Usage
Fill out the booking form with guest details.

Submit the form to simulate a reservation.

Customize styles in style.css to match your design preferences.
